# Operaciones de base de datos

Scripts SQL de mantenimiento y verificacion manual:

- `limpiar_datos_demo.sql`: limpia los datos de demostracion.
- `reiniciar_ids.sql`: reinicia identificadores; revisar antes de ejecutar.
- `verificar_microservicios.sql`: consulta la estructura y estado de las BDs.

Ejecutar desde el cliente MySQL con la base y el entorno correctos. Estos scripts pueden modificar o eliminar datos; revisa su contenido antes de correrlos.
