# Windows helpers

Scripts para desarrollo y reinicio local. Ejecutar desde esta carpeta o desde el Explorador:
- `run_local.bat`: inicia la aplicación web local.
- `run_all.bat`: abre los cinco servicios en ventanas separadas.
- `restart.bat`: actualiza el marcador Passenger del sitio local.

Los scripts localizan la raíz de `Micrososervicios` automáticamente.
